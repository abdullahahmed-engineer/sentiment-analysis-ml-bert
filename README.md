# YouTube Comment Sentiment Analysis Using Machine Learning and BERT

## Overview
This project explores sentiment classification of approximately 9,000 YouTube comments using traditional machine learning techniques and transformer-based models.

## Objectives
- Analyze sentiment in user-generated YouTube comments.
- Compare traditional machine learning models with BERT.
- Evaluate model performance across different approaches.

## Technologies
- Python
- Scikit-learn
- NLTK
- BERT
- Pandas
- NumPy

## Methodology
1. Data collection and preprocessing.
2. Text cleaning and feature extraction.
3. Model development using Logistic Regression, Decision Tree, and Random Forest.
4. BERT-based sentiment analysis.
5. Model evaluation and comparison.

## Results
- Traditional machine learning models achieved over 84% accuracy.
- BERT achieved approximately 90% accuracy on the positive/negative subset evaluated.

## Key Learning Outcomes
- Text preprocessing and feature engineering.
- Natural language processing.
- Machine learning model development and evaluation.
- Comparison of traditional ML and transformer-based approaches.
